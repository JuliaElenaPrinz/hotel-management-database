
# Hotel Management Database

A relational database project developed as part of a university group assignment.

The database was designed for a hotel management system and includes guests, rooms, reservations, invoices, staff, services and events.

## Database Requirements

The database model was designed to support the following areas of a hotel management system:

- Guest and staff management
- Room and reservation management
- Service bookings
- Maintenance records
- Events and event registrations
- Invoice data

## Technologies

- PostgreSQL
- SQL
- Relational database modeling

## My Contributions

My work focused on database design and SQL:

- Designing the relational database structure
- Creating the SQL tables and relationships
- Defining primary keys, foreign keys and constraints
- Creating SQL scripts with sample data
- Creating JPA entities and enums as part of the original group project

The Java application was primarily developed by my teammate and is not included in this repository.

## Project Structure

- `schema.sql` – Database tables, sequences and constraints
- `sample-data.sql` – Sample data for the database
- `docs/database-model.pdf` – ER diagram and relational model

## How to Use

1. Create an empty PostgreSQL database.
2. Execute `schema.sql` to create the database structure.
3. Execute `sample-data.sql` to insert the example data.

## Project Status

University project. The SQL scripts have not been independently retested for this portfolio.
